# Receipt fonts

Libertinus Serif Regular, Bold, and Italic are the unmodified TrueType files
from [Libertinus 7.051](https://github.com/alerque/libertinus/releases/tag/v7.051),
distributed under [OFL 1.1](OFL.txt). The OpenType files from this same release
are the fonts used by the Go receipt renderer. mPDF reads the TrueType format.
